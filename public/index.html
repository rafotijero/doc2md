    Cómo funciona

    Este sitio corre en un Worker de Cloudflare, que verifica la petición y la envía a una API en Python alojada en Hugging Face Spaces. Esa API usa pdf-inspector para el texto embebido, Tesseract y OpenCV para el OCR, y python-docx para los archivos de Word.

    Privacidad

    Los archivos se procesan en memoria y no se guardan. Aun así, pasan por servidores de terceros: no subas documentos confidenciales.
